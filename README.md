# 油站保供调度台账

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

本地可续作的保供台账，替代原先「整条记录覆盖」的保存方式：

- **站点台账**：每站登记安全库存、可用车位（每时段车位数）和保底油量。
- **改派占位**：改派先占用目标站车位（同一车次只算一辆车，占用随改派「移动」而非复制）；目标站容量不够时保留原派单，并显示最早可用时段，可一键按该时段占用。
- **待同步队列**：断网操作进入队列并持久化，刷新/断网后可续作；恢复后按站点、车次和字段基线合并，幂等键保证重复改派只生效一次。
- **冲突待处理**：同一车次两边都改过时保留本地与服务端两版，未处理前该车次不能继续占用；可保留本地（按服务端当前值重建基线重试）或保留服务端。
- **同源读取**：地图、库存统计、待处理清单均读取同一份已确认结果；同步失败保留原操作可重试，已确认派单不可回退。

演示：页头可切换「断网模式」与「服务端故障」；派单卡片上的「模拟对端改派」用于制造同一车次两边都改过的冲突场景。数据保存在浏览器 localStorage（服务端快照与本地队列分键存储）。
